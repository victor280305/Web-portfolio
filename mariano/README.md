# Mariano Web Portfolio

Flet web portfolio for Mariano, an electrical engineering student. It follows the `Web_Portfolio_2026.pdf` requirements:

- Project Timeline
- MATLAB Achievement Hub with 8 course slots
- Technical Blog with notation and video inserts
- GitHub Evidence with commits, pull requests, and impact summary

## Run locally

```powershell
python -m pip install -r requirements.txt
flet run --web --port 8566 main.py
```

Then open:

```text
http://127.0.0.1:8566
```
